# AuctionHyper: release

Qui ci sono solo gli installer di AuctionHyper (app companion per Windows con l'addon per
World of Warcraft: Forever) e il file `latest.json` che l'app legge per aggiornarsi da sola.
Il codice sorgente non è qui.

- Installa l'ultima versione dalla pagina **Releases** (`AuctionHyper_<versione>_x64-setup.exe`).
- Dopo la prima installazione l'app controlla da sola gli aggiornamenti (disattivabile in
  Impostazioni) e aggiorna anche l'addon nella cartella di WoW.
- Ogni installer è firmato: l'app rifiuta un aggiornamento con una firma diversa.
